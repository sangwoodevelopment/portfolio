# Backend Developer Portfolio

A minimal portfolio built with Next.js 15, TypeScript, Tailwind CSS, App Router, and Lucide icons.

## Customize

- Update personal details and skills in `data/site.ts`.
- Update project copy and links in `data/projects.ts`.
- Add a résumé to `public/` and replace the disabled résumé control in `app/page.tsx` with a link.

## Run locally

```bash
npm install
npm run dev
```
